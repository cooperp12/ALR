# BOTSv3 sourcetype quick reference

- `aws:cloudtrail`: AWS API/IAM/EC2
- `stream:smtp`: SMTP/email content
- `ms:o365:reporting:messagetrace`: O365 mail metadata
- `WinEventLog:Security`: Windows authentication/security
- `XmlWinEventLog:Microsoft-Windows-Sysmon/Operational`: endpoint telemetry
- `suricata`, `stream:tcp`, `stream:http`: network/HTTP
- `stream:dns`: DNS
- `code42:security`: file exposure
- `osquery:results`: host/IR telemetry
